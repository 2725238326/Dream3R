# Dream3R v1.1.0 代码提交说明

老师您好：

本压缩包为 Dream3R v1.1.0 的代码提交版，主要包含状态条件化多专家三维重建融合模型的核心实现、proposal-cache 训练入口、运行示例、回归测试和接口文档。

建议按以下顺序查看：

1. `README.md`：项目概览与快速运行方法。
2. `MODEL_CARD.md`：模型结构、输入输出与实验指标。
3. `TRAINING.md`：训练 cache 和 checkpoint 格式。
4. `dream3r/`：核心模型与训练代码。
5. `tests/`：正式接口回归测试。

快速验证命令：

```bash
python -m pip install -r requirements.txt
python -m pytest
python -m dream3r.scripts.smoke_release --output smoke_result.json
```

说明：本包不包含 KITTI、ETH3D 数据集、第三方专家模型及其权重。项目正式指标来自既有实验记录；未加载训练 checkpoint 时，示例仅用于验证模型结构、张量接口和前向传播。
