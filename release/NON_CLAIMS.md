# Dream3R RC Non-Claims

Date: 2026-06-05

This release candidate does not claim:

- SOTA on KITTI, ETH3D, or any public leaderboard.
- That VGGT-Omega improves Dream3R as a full state-causal model.
- That Qwen/VLM outputs provide geometry.
- That a native Dream3R decoder can replace proposal teachers yet.
- That all dynamic/long-sequence cases are solved.
- That the current cache/control results are enough for a paper-scale final
  evaluation.

It does claim:

- a reproducible bounded baseline with state-causality controls;
- real proposal-teacher evidence;
- an admitted VGGT-Omega backend for future domain-conditional teacher work.
